= Create and Manage Projects

The *_Projects_* page is your portal to:

* Create new *Kineviz* projects, review existing projects, and manage shared projects.
* Review details of your *Kineviz* account, link to *Kineviz* information, send feedback to Kineviz, and access user communities.

== Project Display

The *_Projects_* page displays existing projects available to your account. You can open  any project simply by clicking on its card or list item. 

image::/v3/01_03_01_ProjectsHomeCards.png[,720,840,role=text-left]

By default, Projects appear as cards in the following sections:  

* *_Recent Projects_*, projects you recently opened.
* *_My Projects_*, projects you've created, plus a *_Create_* tile or button. 
* *_Shared Projects_*, the projects other users share with you.
* *_Create From Sandbox_*, pre-configured projects focused on specific workflows. Opening a sandbox project clones it and displays it in the *_My Projects_* and *_Recent Projects_* sections.

+
NOTE: Kineviz provides in-app tutorials as *_Sandbox_* projects. Each focuses on a particular use case or workflow, and illustrates how to use the *Kineviz* platform to investigate and communicate useful results.
+

* *_Demo_*, projects, which may be provided for hands-on exploration.

Click the *_Table_* icon at the top of the *_Recent Projects_* section to display a more compact list of your projects. 
 
image::/v3/01_03_02_ProjectsHomeTable.png[,720,520,role=text-left] 

== Create a Project

You can create and configure a *Kineviz* project at any time and optionally connect it to an external or internal database. 

image::/v3/01_03_03_CreateDatabaseType.png[,420,320,role=text-left] 


=== About Database Connection

You can establish a project's database connection(if any) at any time. You must enter connection details and follow the steps required by the database type you select.

NOTE: You can also *_Edit_* the database type and connection details for an existing project.

The *_Database Type_* options are:

* *_None_*, to create a project with no connected database. You can import and model data in formats such as CSV, SQL and JSON, and import graph data via GXRF files, Snapshot archives, and more. Simply drag and drop files directly, or use the *Kineviz* xref:data-import/import-via-mapping.adoc[*Mapping Editor*] for initial graph modeling.

* *_KoreDB_* or *_KoreDb via proxy API_*, to create and connect a default internal KoreDB graph database that you can manage in the *_Project >  Data Store_* subpanel. You can import and/or model graph data in the project, save and query it internally, and export the entire KoreDB database for archival. 

* One of the following relational or graph database types, to enable full *Kineviz* property graph visualization and analytics with no need to replicate or move data:  

** Neo4j 
** BigQuery Property Graph
** Spanner Property Graph
** Puppygraph
** Ultipa Graph
** Memgraph
** GalaxyBase
** Nebula Graph
** Oracle Graph
** Database Proxy. A generalized proxy built on open-source middleware, designed to securely connect *Kineviz* to various backend databases. 

NOTE: *Kineviz* *_Explorer_*, a basic version of the *Kineviz* platform for initial visual exploration of big data, is provided through the *Google Cloud Platform (GCP) Marketplace*. Configuration and connection is exclusively initiated through two *GCP Marketplace* products: xref:explorer:spanner-intro.adoc[*Explorer for Spanner Graph*]  and  xref:explorer:bigquery-intro.adoc[*Explorer for BigQuery*]

=== Create a New Project

*To create a new project:*

. Click *_Create_*, at the top right of the *_Projects_* page.
+
image::/v3/01_03_04_ProjectsCreateButton.png[,720,280,role=text-left]
+
. In the *_Create New Project_* dialog: 
.. Enter a descriptive *_Project Name_* in the text box.

.. In *_Apply Template_*, either leave the default *_None_*, or select a template from the menu. Templates specify colors, icons and other UI configuration settings for easy re-use. 

.. Select the *_Database Type_* from the dropdown menu and click *_Confirm_*.

+   
With a *Database Type* of *_None_* or *_Internal Data Store_*, the project is automatically created and opened.
+

+ 
For connection to an existing external database, the *_Create New Project_* dialog shows the additional details needed to confirm connection to your database.
+
 
+
image::/v3/01_03_05_CreateUltipaProject.png[,420,480,role=text-left]
+

+
* Most connection options require:

 ** Hostname (or IP)
 ** BOLT port - a default is shown for most options.
 ** Username
 ** Password
 ** Database Name 
+
 
+
NOTE: You may also need to verify that your external database is running before trying to connect to it. 
+

+ 
  
* For GCP Spanner and Big Query property graphs, you select the database type abd click *_Confirm_*. 

+
image::/v3/01_03_06_CreateBigQuery.png[,420,480,role=text-left]
+

+
A connection wizard then guides you through a detailed secure deployment process which ends by opening the project.
+

+
image::/v3/01_03_07_CreateBigQueryWizard.png[,520,480,role=text-left]
+

* If you choose the *Kineviz* Database Proxy, which is designed to securely connect *Kineviz* to various backend databases, an API url is required.


. To see that the new project now appears under *_My Projects_*, you must exit the project and return to the *_Projects_* page. Click the Kineviz logo at the lower left and choose *_Home_*. 

=== Create a Project from a Sandbox

Clicking on a project in the *_Sandbox_* section of the *_Projects_* page clones the sandbox project and opens it. 

The new cloned project appears in *_My Projects_* and *_Recent Projects_* sections.

IMPORTANT: After creating a project from a sandbox, once you leave the project and return to the *_Projects_* page, be sure to re-open it in *_My Projects_* or *_Recent Projects_*, not from the *_Sandbox_* section. This returns you to the project as you last left it, instead of creating a new cloned project. 

A sandbox project includes full *Kineviz* functionality, including database connection, project styling template, and any saved views, *Grove* notebooks, and *Agent* setup. Once configured, the project appears on the *_Projects_* home page in the *_Create from Sandbox_* section. 

image::/v3/01_03_09_SandboxCreate.png[,540,420,role=text-left]

 
== Work with Existing Projects  

A tile or list item includes information and tools to review and configure a project:

* *Project name*
* *Database badge* showing the database type connected to the project (if any), e.g. *NEO4J*, *SPAN* (Spanner Graph), *PUPPY* (Puppygraph), *KUZU* (for the internal project database), etc.
* *Sandbox* badge on pre-configured sandbox projects. 
* *Corner badge* in the upper right of a card, to display user-defined text.   
* A *_Settings_* icon, for a dropdown menu of options to edit and share the project:

+
image::/v3/01_03_10_ProjectsSettingsIconMenu.png[,320,320,role=text-left]
+

** *_Edit_* project name, template, and/ or database type.
** *_Clone_* to create a duplicate of the project, including its views and internal database (if any).
** *_Export Project_*, to export the entire project, downloading it to your system as a _.graphxrproject_ file.
** *_UI Configuration_*, to configure user interface elements the sharing user sees, for example, to limit features to only those needed for collaboration.
** *_Share Project_* to share the project with another user of the Kineviz account. 
** *_Open Views_* to open views and generate iframe code that you can include in a report, proposal, or other communication.
** *_Enable / Disable Sharing_* to toggle the project between sharing and non-shared status.
** *_Protect from Deletion_*, to set a flag to prevent project deletion. 
** *_Delete_* (trash can), to delete the project, its saved views and internal graph database (but not data in an external connected graph database).


* The project decription (if any).
* The date the project was *_Created_*, and the date it was last *_Opened_*.
* For *_Sandbox_* projects, the *_Author_*.

=== Edit a Project 

A project is configured according to the template applied (if any), the database type, and other default UI settings. You can change these details at any time. 

. In a Project tile or list item, click its Settings or Actions icon to display the dropdown menu, and select *_Edit_*.

+
image::/v3/01_03_12_EditProject.png[,320,320,role=text-left]
+

. In the *_Edit Project_* dialog change the project name, template, and/ or database type, and click *_Confirm_*.

+
image::/v3/01_03_12a_EditProjectDialog.png[,320,420,role=text-left]


=== Clone a Project 

* In a Project tile or list item, click its Settings or Actions icon to display the dropdown menu, and select *_Clone_*.

+
A duplicate of the project is created, optionally including its *_Grove_* notebooks.
+

+
NOTE: In a *Kineviz* Server project, views are cloned if the *_Copy when cloning project_* checkbox is selected in the view's *_About_* dialog. In *Kineviz Desktop*, all project files and views are cloned by default. 

=== Share a Project

You can share a project with other *Kineviz* users. To collaborate with those who don't have a *Kineviz* account, share individual views securely via iframe.

. In a Project tile or list item, click its Settings or Actions icon to display the dropdown menu, and select *_Enable Sharing_*.
. Now select *_Share Project_*

+
image::/v3/01_03_13_ShareProject.png[,320,180,role=text-left]
+

. Select a sharing user from the dropdown menu, and click *_Invite_*.

=== Open Views to Share

You can select project views and generate iframe code that you can share in an email, report, proposal, or other communication.

. In a Project tile or list item, click its Settings or Actions icon to display the dropdown menu, and select *_Enable Sharing_*.
. Click *_Open Views_* 

. In the list of project views, either click

+
* *_Open view_* to open the view in a separate browser window.
* *_Generate iframe code_*, which is copied to the clipboard for sharing with an external user. 

+
image::/v3/01_03_14_OpenViews.png[,420,320,role=text-left]

=== Configure a Sandbox Project

A cloned sandbox project is not itself a sandbox. However, as you work in the project, you could find it worthwhile to configure it as a new sandbox. Configuring a project as a sandbox lets you set up a working environment for specific  workflows that can then be used as a starting point for similar follow-on projects. 

image::/v3/01_03_15_SandboxIntro.png[,540,420,role=text-left]

You can either:

* Configure any open project as a sandbox by going to *_Project >Settings > Advanced Settings_*, or
* *_Create_* a new project (choosing a *_Project Name_*, *_Database Type_*, and optional *_Template_*). When the project opens, you can then configure it as a sandbox.  

*To configure a project as a Sandbox:* 

. Open the project (or *_Create_* a new one).
. Open the *_Project_* panel and *_Settings_* subpanel, and click *_Advanced Settings_*.

+
image::/v3/01_03_16_SandboxAdvancedSettings.png[,420,320,role=text-left]
+

. Scroll down to see Sandbox configuration options at the bottom of the panel.

. Click the *_Sandbox Project_* checkbox.
. Set sandbox configuration options:

+
image::/v3/01_03_17_SandboxConfigOptions.png[,420,260,role=text-left]
+

+
* *_Description_* text box. Enter a brief description of what the sandbox contains.
* *_Protect from deletion_* checkbox.
* *_Grove_* book display options:

** *_Open Grovebook on Load_*. Enter the Grovebook file key (e.g. my-notebook)
** *_Open Grovebook on Load Display Mode_*. Choose *_Left_* to dock your Grovebook to the left menu, or *_Floating_* to float it on the canvas.

* *_Project Icon_*. Enter a custom icon for the sandbox. By default, a flask icon (fa-flask) is displayed.
* *_Open View on Load_*. Select one of the project's saved views from the dropdown menu.
* *_Tags_*. Enter optional tags that indicate intended sandbox usage (e.g. Beginner, Recommended, etc.) 
* *_Card Preview Image_*. Click *_Upload Image_* or *_Remove Image_* to control the preview image (such as a screenshot of one of the project views) that appears on the project tile.
* *_Corner Tag_*. Enter a user-defined tag that will appear at the upper right of the project tile to further specify intended sandbox usage (for example *_Agent Tools_*, *_Native Tools_*).
+

+
image::/v3/01_03_18_SandboxDesktopOptions.png[,420,420,role=text-left]
+

+
The configuration is set as soon as you enter the details.
+

.  Return to the *_Projects_* home page to verify that the project now appears in the *_Create from Sandbox_* section.
