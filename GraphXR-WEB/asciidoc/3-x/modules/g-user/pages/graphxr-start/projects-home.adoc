= Create and Manage Projects

The *_Projects_* (or *_Home_*) page is your portal to:

* Create or import *Kineviz* projects, and optionally connect to an external or internal database.
* Review and edit existing projects, including shared projects, sandboxes and demos.

image::/v3/01_03_01_ProjectHome.png[,720,340,role=text-left]

Project *_Cards_* display project details and editing options. The *_Table_* icon at the top right lets you display a more compact project list.  

image::/v3/01_03_02_ProjectsTable.png[,720,520,role=text-left]

== Database Connection to Kineviz Projects

A Kineviz project can be connected to an internal KoreDB database or one of several external databases when you create it. The options are:

* An Internal *_KoreDB_* or *_KoreDB via proxy API_*, to create and connect a default internal KoreDB graph database queried using *Cypher*. You can import and/or model graph data in the project, save and query it internally, and export the entire KoreDB database for archival. 

* An external graph database, to enable *Kineviz* property graph visualization and analytics without replicating or moving data.   

NOTE: Connecting a project when you create it is optional, and you can *_Edit_* connection details for an existing project at any time. 

To review a list of currently supported databases:

. Click *_New Project_* at the upper right of the *_Project_* home page. 
. In the *_New Project_* dialog, click *_Your Database_* to display the list.

== Create a Project

You can create and configure a *Kineviz* project at any time and optionally connect it to an external or internal database. You can:

* create a new project manually
* create a project by prompting the built-in Kineviz *_Agent_*  
* start from a pre-configured sandbox project.

=== Create a New Project

*To create a new project:*

. Click *_New Project_*, at the top right of the *_Projects_* page.
+
image::/v3/01_03_05_ProjectsCreateButton.png[,720,180,role=text-left]
+

. In the *_New Project_* dialog: 

.. Select the optional database connection (or skip connection):

+   
* Click *Empty Graph* to automatically create an internal *_KoreDB_*. 
* Click *Your database* to select an existing external database. The databases Kineviz supports are listed in the dropdown menu in *_Cypher_*, *_Gremlin_*, *_GQL/PGQL_*, or *_Other_* sections. To more easily locate the desired database, select the menu's *_Grid_* view and either enter a search in the search bar, or click to display only the list for a section. Then click to select the database you want.
* Click *_Skip database_* below the *Your database* menu to create a project with no connected database. You can import and model data in formats such as CSV, SQL and JSON, and import graph data via GXRF files, Snapshot archives, and more. Simply drag and drop files directly, or use the *Kineviz* xref:data-import/import-via-mapping.adoc[*Mapping Editor*] for initial graph modeling.
+

+ 
If you select an external database, additional details needed to confirm connection to your database are displayed.
+

+
image::/v3/01_03_06_CreatePostgreSQLProject.png[,420,480,role=text-left]
+

+
NOTE: You may also need to verify that your external database is running before trying to connect to it. 
+

+
* Most database types require:

 ** Host (or IP)
 ** Port - a default is shown for most options.
 ** Database
 ** Username
 ** Password
 ** Database Name 
+
 
+  
* For GCP Spanner and Big Query property graphs, when you select the database type and click *_Confirm_*, a connection wizard guides you through a detailed secure deployment process which ends by opening the project.
+

+
image::/v3/01_03_07_CreateBigQueryWizard.png[,520,480,role=text-left]
+

+
* The *Kineviz* Database Proxy which securely connects *Kineviz* to various backend databases requires an API url.
+

.. In *_Apply Template_*, either leave the default *_None_*, or select a template from the menu. Templates specify colors, icons and other UI configuration settings for easy re-use.
.. Enter a descriptive *_Project Name_* in the text box. A name is automatically suggested; you will likely want to change it.
.. Enter an optional project *_Description_*. You can add or edit this later if desired.
.. Enter or select optional *_Tags_* that indicate the general topic or audience for the project.
.. In *_Slug_*, enter an optional short name to be used in the project's share link instead of its id. Use a name unique to the server of 3–64 characters with lowercase letters, numbers and hyphens only. 
+
image::/v3/01_03_08_ProjectNameDesc.png[,720,480,role=text-left]
+

+
The project card that will be displayed on the *_Projects_* page is updated as you enter details. Click *_Upload image_* to upload an optional thumbnail image to display on the card, or you can do it later.
+

. Click *_Create and Open_* to create the new project and open it, *_Create only_* to create the project and return to the *_Projects_* page, or *_Cancel_* to return to the *_Projects_* page without creating a project.

+

+

The project opens, starting a chat in the *_Agent_* panel where you can specify the data and model and direct agentic exploration and visualization.

=== Create a Project from a Sandbox

A sandbox is a pre-configured project that you can duplicate. It can include a database connection, data views, styling templates, and any Kineviz extensions it uses. A project created from a sandbox is cloned and automatically opened. 

NOTE: Kineviz provides in-app tutorials as *_Sandbox_* projects that show how to create and explore graph data, and communicate useful results. You can flag any of your existing projects as collaborative sandboxes for your specific use cases. 
 
*To create a project from a sandbox:*

. On the projects home page, in the *start a project* area near the top, click *_From a sandbox_*.
+
image::/v3/01_03_12_ProjectsStartSandbox.png[,720,280,role=text-left]
+

. In the *_Start from a Sandbox_* dropdown, locate the sandbox. You can click the link at the bottom of the short list to display all the sandboxes available to your account.

+
image::/v3/01_03_13_ProjectsSandboxChoose.png[,420,280,role=text-left]
+
 
. Click the card for the sandbox you want to copy (or click the Kineviz logo at the top to return to the *_Projects_* page without creating a new project.)

+
The new project is created and opened, named  _Sandbox Name (n)_ (for example _Books Sandbox (1)_.
+

+
image::/v3/01_03_14_SandboxCreated.png[,540,420,role=text-left]
+

+
NOTE: To re-name the project, choose *_Edit_* in the project split view menu at the top center of the canvas, and in the *_Edit Project_* dialog, enter the new name and click *_Confirm_*. 
+

+
A project created from a sandbox  includes the database connection (if any), saved data views, UI configuration, and workspace configuration, *Kineviz Notebooks*, and *Agent* setup present in the sandbox. It is not itself a sandbox, so its project card or list does not display the blue flask icon. 

 
== Work with Existing Projects  

All the projects existing in your account are displayed on the *_Kineviz_* home page. You can:

* Review projects in either a *_Card_* or *_Table_* (tabular list) format. 
* Sort, search and filter Projects
* Click a project card or list item to open it.
* *_Jump back in_* to any of the last four recently opened projects.
* Add to or remove from *_Favorites_*
* *_Edit_* project details including name, description, tags, database connection, and sandbox status. 
* *_Import_* a project
* *_Clone_* a project
* *_Export a Project_*
* *_Transfer ownership_* of a project
* *_Delete_* a project, unless it is protected from deletion.

=== Review Projects

On the projects page, projects are displayed in either a *_Card_* or *_Table_* (tabular list). You can click to open a project from either one. 

Both formats display information and tools to search, sort, review and configure a project. 

NOTE: Project configuration can also be changed within an open project using the split *Project / View* menu at the top center of the canvas. 

==== Project Card Display

A project *_Card_* is created for each project available to your account. 

image::/v3/01_03_15_ProjectsCardDisplay.png[,420,540,role=text-left]

A project card includes:

* A project image area with:

** A window to upload an optional image (card only). You can add or update it at any time, either within an open project, or using the project's *_Edit_* menu.
** A star icon at the top right. Click it to set the project as a *_Favorite_*. 
** A database badge at the bottom left showing the connected database (if any).
* An optional workflow badge (e.g. Agentic, Manual, etc) at the top right. 
* A *Project title*
* A blue flask icon on pre-configured sandbox projects, and a green sharing icon on projects shared with you.
* A lock icon for projects that have been protected from deletion.
* The project description (Card only).
* The date the project was *_Created_*, and the date it was last *_Opened_*.
* For a *_Shared_* project, the *_Author_*.
* A settings icon, for a contextual dropdown menu of options to edit, share, export, or delete the project:

+
image::/v3/01_03_16_ProjectsSettingsMenu.png[,420,580,role=text-left]
+

** *_Add to Favorites_* / *_Remove from Favorites_*.
** *_Edit_* project name, template, and/ or database type.
** *_Clone_* to create a duplicate of the project, including its views and internal database (if any).
** *_Export Project_*, to export the entire project, downloading it to your system as a _.graphxrproject_ file.
** *_UI Configuration_*, to configure user interface elements the sharing user sees, for example, to limit features to only those needed for collaboration.
** *_Share Project_* to share the project with another user of the Kineviz account. 
** *_Open Views_* to open views and generate iframe code that you can include in a report, proposal, or other communication.
** *_Enable / Disable Sharing_* to toggle the project between sharing and non-shared status.
** *_Transfer ownership_*, to transfer control of a project to another user. 
** *_Allow_* or *_Protect from Deletion_*, to set a flag to prevent project deletion. 
** *_Delete_* (trash can), to delete the project, its saved views, and internal graph database (but not data in an external connected graph database), if deletion is allowed.

==== Project Table Display

The *_Table_* display option is a more compact table or list. It includes most of the information and editing options available on the cards, as well as the same project search and filter options as in the *_Card_* display. 
 
image::/v3/01_03_17_ProjectsTableList.png[,720,420,role=text-left]

The *_Table_* display includes:

* Compact, sortable lists of projects in separate *_My Projects_* and *_Shared Projects_* sections. Sandbox and lock icons are displayed with the project *_Name_*   
* The settings dropdown menu for project editing options, located in the *_Actions_* column on the far right.

+
NOTE: Project image, tags, and description are only shown on the card or in the *_Edit Project_* dialog. 


=== Sort, Search, and Filter Projects

To display only specific projects, you can use pre-defined sorting and filters, and/or the project search bar. 

image::/v3/01_03_18_ProjectsSortSearchFilter.png[,720,420,role=text-left]


==== Sort displayed projects

In the *_Card_* display, use the dropdown sort menu to sort projects by:   
* Project name
* Date created  
* Date last opened
* Author
 
In the *_Table_* display, simply click arrows next to a table heading to sort in ascending or descending order.
 
==== Search for a specific project

To display a specific project, enter all or part of a name, author, tag, or description in the *_Search_* bar at the top of the page. 

The search operates on currently displayed projects, and a search term is applied until you remove it. 

==== Filter projects

Pre-defined filters appear on the left menu bar. 
 
* Default filters include:

** *_All Projects_*, projects you've created, shared projects, and sandbox projects.
** *_Favorites_*, projects where you've clicked the *star* icon on the project card or  *_Add to Favorites_* on the edit menu in a table view. 
** *_Shared with me_*, projects other users have shared with you.     
** *_My sandboxes_*, sandbox projects available to your account.

* Additional pre-defined filters can be chosen from the *_Add Filter_* menu, including:
** User-defined project *_Tag_* (e.g. Beginner, Intermediate, etc.)
** Date last *_Opened_*, displaying a slider control to filter projects from the previous 7 to 90 days.
** Date *_Created_*, displaying a slider control to filter projects from the previous 7 to 90 days.
** *_Database Type_*
** Project *_Authors_*
** Projects with *_Deletion protection_*

+
image::/v3/01_03_19_ProjectsAddFilter.png[,420,520,role=text-left]


=== Open a Project

To open a project, simply click its card or list item. 

To open a recent project, you can either:

* Search for projects by *_Date last opened_*
* Click *_All Projects_* to display a *_Jump back in_* section with cards for the last four project you opened. The small cards show how long ago each project was last opened. Click a card to open the project.

+ 
image::/v3/01_03_20_ProjectsJumpBackIn.png[,720,540,role=text-left]
+
+
NOTE: Project sorting and filters do not apply to the *_Jump back in_* section. 
    

=== Edit a Project 

The *_Edit Project_* dialog lets you change project details at any time. Open it by selecting *_Edit_* on either:

* the settings menu on the project home page, or 
* the split Project / View menu in any open project. 

image::/v3/01_03_21_EditProjectMenu.png[,520,420,role=text-left]

*To edit project details and configuration:*

. In a project's settings dropdown menu, select *_Edit_*.

+
image::/v3/01_03_22_EditProjectDialog.png[,540,420,role=text-left]
+

. In the *_Edit Project_* dialog you can: 

+
* Enter a new *_Project Name_*, optional *_Description_*, and *_Slug_* (short name used in a project's share link)
* Click to select different *_Tags_* to be displayed on the project card. 
* Enter different database connection details.
* Apply or reapply a styling template.
* Flag a project as a sandbox, and specify who it can be shared with. You can flag any existing project as a sandbox, which adds it to *_My Sandboxes_* and makes it available for other users to copy and extend. In the *_Who can open this sandbox_* dropdown, the default is *_Signed in - anyone on this server_*. The other options are *_Public - anyone with the link_*, or *_Restricted - only people you share it with_*
+

+
image::/v3/01_03_23_SandboxCheckbox.png[,540,420,role=text-left]
+

. Click *_Confirm_*. 
 
+
Changes take effect immediately on the project page and in the open project:

* A changed project name and configuration details are immediately updated 
* When you flag the project as a sandbox:
** A blue _flask_ icon appears on the project card or list.
** The count in *_My Sandboxes_* in the project navigation menu is updated.

=== Clone a Project 

Cloning a project duplicates its description, data, views, and styling. A default name is applied that you can change before creating the clone.

*To clone a project:*

. In the project's settings dropdown menu, select *_Clone_*.
. In the *_Clone Project_*  dialog, optionally enter a new name.
. Click *_Confirm_*

+
A duplicate of the project is created (including any *_Kineviz Notebook_* files), and the project is opened automatically.

=== Export a Project 

You can export an entire project as a _.gxrproject_ file downloaded to your system. This is useful for archiving projects, moving projects offline for later use.

*To export a project:*

* In the project's settings dropdown menu, select *_Export project_*.

+
Messages indicate successful export and download of the named _.gxrproject_ file.


=== Import a Project

Any project exported as a _.gxrproject_ file can be imported into your account. A _.gxrproject_ file includes all project views, the internal database, and the template  and other styling in effect when the project was exported. 

*To import a project:*

. In the *_Projects_* home page, click the *_New Project_* dropdown arrow, and select *_Import Project_*.

+
image::/v3/01_03_24_ImportProjectMenu.png[,720,240,role=text-left]
+

. In the *_Import project_* dialog, click to locate and select the  _.gxrproject_ file (or drag and drop the file).

+
image::/v3/01_03_25_ImportProjectFind.png[,420,340,role=text-left]
+

. Click *_Import_*. 
. When the project is imported successfully, either click *_Open_* to open it, or *_Cancel_* to return to the *_Projects_* home page. 

+
image::/v3/01_03_26_ImportProjectDone.png[,320,180,role=text-left]
+

+
The imported project is named as _Project name (imported)_. To re-name the project, choose *_Edit_* either on the project card or list or in the project split view menu. In the *_Edit Project_* dialog, enter the new name and click *_Confirm_* 


=== Share a Project

You can directly share a project with other *Kineviz* users. 

NOTE: To collaborate with those who don't have a *Kineviz* account, you can share individual views securely via iframe.

*To share a project:* 

. In the project's settings dropdown menu, select *_Enable Share_* 

+
image::/v3/01_03_27_ShareEnable.png[,720,280,role=text-left]
+

. Now select *_Share Project_*

+
image::/v3/01_03_28_ShareProject.png[,320,480,role=text-left]
+

. Select a sharing user from the dropdown menu, and click *_Invite_*.

+
image::/v3/01_03_29_ShareInvite.png[,420,520,role=text-left]
 


=== Share Project Views

You can select project views and generate iframe code that you can share in an email, report, proposal, or other communication.

*To share project views:* 

. In the project's settings dropdown menu, select *_Enable Share_*.
. Now select *_Open Views_* to see the list of project views.

+
image::/v3/01_03_30_OpenViewsList.png[,520,320,role=text-left]
+

. In the list of project views, either click:

+
* *_Open view_* to open the view in a separate browser window.
* *_Generate iframe code_*, copying it to the clipboard for sharing with an external user.
 

=== Transfer Project Ownership

You can transfer ownership of a project to another *Kineviz* user, and choose whether or not you will retain access.

*To transfer project ownership:* 

. In the project's settings dropdown menu, select *_Transfer ownership_*.

+
image::/v3/01_03_31_TransferMenu.png[,240,180,role=text-left]
+


. In the dialog, choose the user from the dropdown menu.

+
image::/v3/01_03_32_TransferProject.png[,380,240,role=text-left]
+

. Optionally de-select the *_Keep me as a collaborator_* checkbox (which is selected by default).

=== Delete a Project

You can delete a project from your account. If it is protected from deletion, a lock icon appears on the project cadd or list item, and you must remove protection first.

*To delete a project:* 

. If the project is protected, in the project's settings dropdown menu, select *_Allow deletion_*.

+
image::/v3/01_03_33_AllowDeletion.png[,720,380,role=text-left]
+

. Once the update occurs, select *_Delete Project_*.

+
image::/v3/01_03_34_DeleteProject.png[,240,180,role=text-left]
