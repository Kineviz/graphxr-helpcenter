= The Project Workspace

The *Kineviz* project workspace is designed to enable users to work seamlessly with the visualized graph and its connected database. It provides a virtual 3D or 2D canvas for visual display, navigation, and layout of the graph, and a configurable set of features and tools for data management and exploratory analytics. 

image::/v3/01_04_01_ProjectOverviewLabeled.png[,720,450,role=text-center]
 
Functions and tools are organized in panels, a legend, a toolbar, dropdown menus, and a live status bar, as follows:

* *Kineviz logo* at the top right, to return to the projects home page.

* Combined *_Query/Search_* bar at the top left of the browser window, to either enter a no-code *Query* on the connected graph database, or a *Search* of property values in the database or on the project canvas.

* Split *Project / View* menus, at the top center of the browser window:
** *Project* menu, to create, open, and manage projects within any open project.  
** *Views* menu, to create and manage the project's data views without opening its *_Views_* panel.

* *_Saved Workspaces_* menu and toggles at the top right of the browser window, to save and apply user-defined workspaces, and show or hide the panels of a workspace. 

+
NOTE: For specific workflows that focus or limit user access to tools and features, you can xref:g-user:graphxr-start/project-ui-config.adoc[*Configure User-defined Project Workspaces*] within an open project. Most *Kineviz* menus and tools can be shown or hidden, and one or more customized panel layouts can be configured and saved as named project workspaces.
+

* *_Legend_*, on the right of the canvas, to display, select, and style nodes by *_Category_*, *_Tag_*, or a category *_Property_* name and value, and edges by *_Relationship_* or a relationship property (*_RelProperty_*) name and value. 
 
* *_Export_* menu, to the right of the legend, to export the entire project or the current data view to your local system.

* *_Panel Menu_* on the left edge of the browser window. Kineviz functions are organized in *_Projects_*, *_Files_*, *_Dashboard_*, *_Query_*, *_Transform_*, *_Table_*, *_Layout_*, *_Filter_*, *_Algorithm_*, *_Agent_*, and *_Map_* panels. Click an item to open its panel.

+
NOTE: Additional panel menu icons are displayed when extensions such as the *_Kineviz Notebook_* and any preconfigured sandboxes are activated.
+
 
* *_Toolbar_* near the bottom of the window, for the available tools to  *_Select_*, *_Edit_*, *_Arrange_*, and *_Display_* the graph, display *_Media_*, undo or redo *_History_* actions, or *_Remove_* data.

* Configurable *_Right-click menu_* of tools and operations usable on your current data selection. Right-click anywhere on the canvas to perform many graph operations without going to the toolbar or opening a panel.

* *Navigation* icons along the bottom right vertical edge, including *_Reset_*, *_Rotate Right_* and *_Rotate Left_* (by 90 degrees), *_Zoom _* controls, *_Center To_*, *_Fly Out_*, and a live *_Minimap_*  thumbnail view of the canvas. 
 
* A *_Status Bar_* at the bottom edge, to monitor the connected database and its categories and relationships, see the number of nodes and edges on the canvas, open tables of nodes and edges, monitor Kineviz *_Agent_* status, and monitor data views. 

* Kineviz *_Help_* menu (question icon) at the bottom of the left panel menu, to display information about the current *Kineviz* version. 

* *User account* menu at the bottom left, to show *Kineviz* information, switch to another project, edit the project theme and language, open the administrator portal, or log out.  

== Query/Search bar

Use the *_Query_* bar (or enter *_Cmd + K_*) to

* Enter a no-code *Query* for data from a connected or internal graph database. 
* Perform full-text *Search* of property values on indexed data in the database, or the data on the project canvas. 

=== No-code graph Query

Click in the *_Query_* bar (or enter *_Cmd + K_*) for a query dropdown menu to build and run a no-code visual query on the connected graph database.

image::/v3/01_04_02_QueryBarQuery.png[,420,240,role=text-left]

NOTE: Once you have data on the canvas, you can optionally use no-code *_Expand with Relationships_* from the toolbar icon or right-click menu to query for additional nodes connected through the defined relationships you select. 

=== Full-text Search

The search bar at the top left also enables full-text search. You can either: 

* Search the indexed properties in a connected database, and import the results to the project, or
* Search data already on the canvas.

+
image::/v3/01_04_03_SearchCanvasDB.png[,240,320,role=text-left]
+

+ 
NOTE: Click *_Configure Search Index_* icon to open a dialog to index the database properties available for search.
+

Search results are listed by category below the search bar. Click a single node or a group of nodes in the search results to either:

* Import the data from the database, or
* Select and center the graph on the nodes already on the canvas.

== Legend

The legend at the upper right corner of the canvas provides selectable lists of nodes or edges by *_Category_*, *_Relationship_*, *_Tag_*, *_Property_* (i.e. properties defined on Categories), or *_RelProperty_* (i.e. properties defined on Relationships).

image::/v3/01_04_07_LegendCatRel.png[,240,380,role=text-left]

Each list bubble displays:

* The entity label (for a category, relationship, or tag) or property value (for a property)
* Number of currently selected nodes or edges with that label or value
* Total number of nodes or edges with that label or value  

Use the legend lists to:

* Review the number of nodes of each category, tag, property (or edges of each relationship), and the number in the current selection.  
* Click a list item to select all its nodes (or edges). 

+
TIP: Use _ctrl-left click_ to select multiple items, and the mouse wheel or scroll gesture to scroll a long list.
+

* Click the colored dot next to a list item to style nodes and edges:
** For a category, you can set *_Color_*, an *_Icon_*, and select properties to be used for one or more *_Captions_*, an *_Avatar_* url, and relative node *_Size_* (based on a property value).
+
image::/v3/01_04_08_Style_Category.png[,240,320,role=text-left]
+
** For a relationship, you can set the *_Color_*, and select properties for *_Captions_* and *_Bind Width_* (relative width of the edge based on a property value).

+
image::/v3/01_04_09_Style_Relationship.png[,240,240,role=text-left]
+

+
** For a listed property value or tag, you can set a *_Color_* and *_Icon_*.

== Panel menu

The *Panel* menu on the left edge of the canvas displays icons to open panels (and their tabbed subpanels) organized by major function. You can:

* Click an icon to display its panel. 
* Click the menu's arrow icon to show or dismiss text labels for each icon.

NOTE: The *Panel* menu is configurable. You can *click + drag* an icon to change the order on the menu. You can also show or hide most panels and extensions, either through *_Settings > UI Configuration_* or *_Project > Extensions_*.  

=== Project panel

*_Project_* opens sub-panels to manage a project's data views, review graph entities, set overall display preferences, manage the datastore, and access extensions:

image::/v3/01_04_11_ProjectPanelView.png[,520,450,role=text-left]

* *_Views_*, to display data views saved to the server, to save, update, select, and annotate views, and to load a data view to the project space. 
* *_Category_* and *_Relationship_*, to review defined graph entities, pull specific types of nodes or edges from a connected database and set display options for entities and their properties.
* *_Settings_*, to set display options for project theme and light/dark mode, nodes,  edges and captions, set the project *_UI Configuration_*, show or hide *_Snapshot_*, *_History_*, *_Quick Info_*, and *_Show recent views on the empty canvas_*, *_Clean Unused Configuration (for Categories and Relationships)_*, and edit the project description and its API *_Secrets_*.
* *_Data Store_*, for *_Utilities_* to *_Import_* data, *_Export_* the project or its data views, *_Save Template_* based on the view on canvas, show and edit the current database *_Schema_*, or *_Hydrate IDs_* of the graph on the canvas. In the *_Data Store_* section,  you can review details for the connected database, create a new instance, *_Save Canvas to KoreDB_*, *_Upload KoreDB ZIP_*, *_Export Database_*, and *_Empty_* or  *_Delete_* the database.
* *_Extensions_*, to import and access Kineviz extensions, either in the panel, or in the Admin portal.  
* *_Grove Links_*, to manage access to Kineviz notebooks available to the project.

=== Query panel

*_Query_* opens sub-panels to enter and save a Cypher or GQL *_Query_* on a connected database, to query *_SQL_* databases (MySQL, MSSQL, PostgreSQL, or ElasticSearch), *_CSV/Excel_* files, and *_JSON_* files.

image::/v3/01_04_14_QueryPanelQuery.png[,520,450,role=text-left]

The *_SQL_* and *_CSV_* tabs include the Kineviz *_Mapping Editor_* to map data in flat files or SQL tables to a graph model.

image::/v3/01_04_15_QueryPanelCSV.png[,520,620,role=text-left]

=== Transform panel

*_Transform_* opens sub-panels for operations to transform graph data directly in GraphXR.

image::/v3/01_04_16_TransformPanelShortcut.png[,520,450,role=text-left]

Transform sub-panels include:

* *_Formula_*, to execute functions similar to formulas in Excel and SQL or functions in MapReduce frameworks. You can run formulas to add information from one column of data to another, or to modify data formats.
* *_Extract_*, to define a new category (and its properties) and relationship from an existing category, and extract new nodes and edges based upon it.
* *_Aggregate_*, to collect properties from a starting node's neighboring edges and nodes, apply a calculation, and write the result to the starting node as a property. This makes it possible to simplify a graph, yet retain key information about its original complexity.  
* *_Merge_*, to combine two nodes with matching properties into a single node.
* *_Link_*, to connect nodes with the same property values. This can be used to bring two different data sets together and also to draw explicit connections among nodes of the same type.
* *_Shortcut_*, to connect two nodes that share a common neighbor with a new link.
* *_Connector_*, to provide access to external applications for enhancing data.

=== Table panel

*_Table_* open live searchable tables of nodes and edges by *_Category_* or *_Relationship_*. You can rename categories and relationships on the fly, select, sort, edit, and reformat data, select (mark) data in the graph on the canvas, and export data as a CSV or Excel archive.

image::/v3/01_04_17_TablePanelCat.png[,520,450,role=text-left]

*_Layout_* opens *_Force_*, *_Parametric_*, *_Geometric_* , and *_Gizmo_* sub-panels for applying detailed layouts to all or part of the data on the canvas. Most layout options are also available from the *_Quick layout_* toolbar or right-click menu. 

image::/v3/01_04_18_LayoutPanelGeom.png[,540,620,role=text-left]

NOTE: The *_Gizmo_* is a tool to rotate and scale all or part of the graph directly on the canvas. Its tab in the *_Layout_* panel lets you specify the rotation axes that appear, or enter and apply numerical values to move, rotate, and scale a selection (similar to those you can enter in the *_Layout_* panel).

image::/v3/01_04_19_LayoutPanelGizmo.png[,420,520,role=text-left]


=== Filter panel

*_Filter_* opens a panel to filter and select data by multiple _Node_ or _Edge_ property values. You can filter on numerical property values including date-time and latitude/longitude, as well as categorical(text string) property values.

image::/v3/01_04_20_FilterPanel.png[,520,520,role=text-left]

== Right-click Context Menu

A customizable floating context menu of the tools available for your current selection is available by right-clicking anywhere in the project space. Use it to navigate and edit the graph without using the toolbar or opening additional panels.

The default right-click menu includes often-used options at the top level: *_Information_*, *_Expand_*, *_Find Path_*, and *_Delete_*. 

image::/v3/01_04_40_RCSelectActionsLayout.png[,720,520,role=text-center]

The *_Select_*, *_Actions_*, and *_Layout_* submenus organize related options:

* *_Layout_* submenu: *_Line_*, *_Grid_*, *_Cube_*, *_Circle_*, *_Sphere_*, *_Spiral_*, *_Tree_*, and *_Ring_* layouts, and  options to *_Expand_*, *_Contract_*, and *_Rotate_* a layout operate on selected data, or all data if nothing is selected. Layouts are grayed out if unavailable for the data.

* *_Select_* submenu: *_All Nodes_*, *_Add to Selection_*, *_Subtract from Selection_*, *_Invert_*, *_Deselect_*, *_Floating Nodes_*, *_Leaf Nodes_*, *_Neighbor Nodes_*,  *_Child Nodes_*, *_Parent Nodes_*, *_Neighbor Edges_*, and *_Connected Nodes_*.

* *_Actions_* submenu: *_Add Node_*, *_Add Edge_*, *_Merge Nodes_*, *_Change Category_*, *_Collect Nodes_*, *_Explode Nodes_*, *_Tag_*, *_Hide_*, *_Show Hidden_*, *_Pin_*, *_Release_*, *_Highlight Nodes_*, and *_Clear Highlights_*.

+
NOTE: *_Quick Information_*, the *_Force Layout_* toggle, *_Clear_*, *_Screenshot_*, *_Link_*, *_Gizmo_*, and *Enlarge Avatar* tools appear only in the toolbar.

The following table lists functions available only in the right-click menu. The other functions in the menu are also available in the toolbar or a panel. 

[cols="3,6"]
|===
| *Right-Click Menu Only* |*Function*

| *_Find Path_*
| Similar to the function in the *_Algorithm>Path Finding_* tab, but finds a path between just two selected nodes.

| _Select_ > *_Add to Selection_*
|  Mouse over an unselected node, and add the node to already selected nodes.

| _Select_ > *_Subtract from Selection_*
| Mouse over a selected node, and de-select the node.

| _Select_ > *_Floating Nodes_*
| Select nodes with no connecting edges.

| _Select_ > *_Leaf Nodes_*
| Select nodes with only one connecting edge.

| _Select_ > *_Neighbor Nodes_*
| Select nodes one hop away from selected nodes. Choose again to select nodes another hop away. One hop at a time is found and the nodes selected, not just highlighted.

| _Select_ > *Child Nodes_*
| Select nodes one forward hop away from selected nodes (as shown by the direction of the connected edge). Choose again to select nodes another hop away.  

| _Select_ > *_Parent Nodes_*
| Select nodes one reverse hop away from selected nodes (as shown by the direction of the connected edge). Choose again to select nodes another hop away. 

| _Select_ > *_Neighbor Edges_*
| Select nodes one edge away from selected nodes.

| _Select_ > *_Connected Nodes_*
| Select nodes connected to selected edges.

| _Actions_ > *_Merge Nodes_*
| Displays a dialog to merge any selection of nodes into one node.  

| _Actions_ > *_Change Category_*
| Displays a dialog to change the category of any selection of nodes to any other existing category or to a new category. Properties of the changed nodes not present in the target category are transferred.

| _Actions_ > *_Highlight Nodes_*
| Adds a colored ring around a node to as a persistent highlight.    

| _Actions_ > *_Clear Highlights_*
| Clears the highlight ring on selected nodes.  

|===

WARNING: *_Actions>Change Category_* and *_Actions>Merge_* cannot be undone with Ctrl+Z. Before using either option, save a data View, snapshot, or .graphxr file so that you can undo a mistaken change.

== Navigation Icons

One-click navigation icons are displayed along the lower right vertical margin of the canvas.

image::/v3/01_04_41_NavTools.png[,320,280,role=text-left]

* *_Reset_* the view to the center point of the data (similar to *_Center To_*).
* *_Rotate Left_* or *_Rotate Right_*.
* Zoom *_In_* or *_Out_*, or open the slider controlling zoom percent.
* *_Center To_*, to zoom in on the center of the graph if no nodes are selected, or the center of a group of selected nodes, or a single selected node.
* *_Fly Out_*, to zoom out, automatically fit, and center the entire graph on the visible canvas. 
* *_Minimap_*, to display a live thumbnail view of the entire graph. *_Click + drag_*  on the image to reposition the entire graph (usually faster than navigating on the canvas). You cannot rotate the thumbnail image. 
+

== User account menu

The user account (person) icon displays a menu to show information, switch to another project, edit the project theme and language, open the administrator portal, or log out.

image::/v3/01_04_44_UserMenu.png[,420,380,role=text-left]

* *_Home_*. Return to the *_Projects_* home page.
* *_Recent Projects_*. Switch to another existing project, or *_Create New Project_*. 
*_Theme_*. Choose *_Light_* or *_Dark_* mode, or *_Match Theme_* to match the theme to the browser setting.  
*_Language_*. Choose a different UI language (defaults are English, Chinese, or Spanish).
* *_Shortcuts_*. Display a quick reference card of desktop shortcut keys. See  xref:nav-select/ref-shortcut-keys.adoc[Shortcut Keys Reference].
* *_About_*. Current *Kineviz* version and release information. The *_Help_* (question mark) icon above the user account menu displays the same dialog. 
* *_Admin_*. Open the Administrator panel (if available to your user account).
* Current logged in user *account ID*.
* *_Logout_*. Log out of *Kineviz*.
