= Run Graph Algorithms

The *_Algorithm_* panel provides a library of algorithms widely used to analyze patterns of graph connection. 

image::/v3/07_00_01_AlgorithmPanel.png[,720,380,role=text-left]

For a graph visible on the canvas the options are:

* *_Path Finding_* traces the path between a set of selected start and end nodes,  optionally weighted based on a relationship property. Once traced, you can spotlight the path to tag or save it.

* *_Centrality_*, *_Community_*, and *_SNA_* (Social Network Analysis) algorithms calculate a property and value for each node that measure various aspects of its connectedness or grouping within the graph.  

* In addition to property values an algorithm adds to each node, rapid summaries of results are displayed for the graph as a whole.

== Path Finding

*_Path Finding_* traces the shortest path between selected start and end nodes. 
Once a path is traced, you can click *_Spotlight Path_* to display only its nodes and edges.

*To find a path between connected nodes:*

. Open the *_Algorithm_* panel and *_Path Finding_* tab.

. Select one or more starting nodes in the graph, and click *_Add to Start_*.  
. Now select ending nodes in the graph, and click *_Add to End_*.

+ 
The selected nodes are listed in *_Start Nodes_* and *_End Nodes_*, respectively.
+

+
NOTE: With more than ten pairs of nodes selected, an error message advises you to choose fewer nodes. You can click *_Remove Start Node_* or *_Remove End Node_* to delete your current selection and choose other nodes. 
+

. Optionally, in the *_Weight Property_* menu, choose a property of one of the relationships as a path weighting value. The default is *_Ignore Weight Property_*. Often, the relationships have no properties, so that *_Ignore Weight Property_* is the only choice.
. Click *_Trace Path_* to display and select the nodes and edges for the shortest path(s) between the start and end nodes.

+
image::/v3/07_01_01_AlgorithmPath.png[,520,380,role=text-left]
+


. Click *_Spotlight Path_* to display only the nodes and edges in the path. The button  changes to *_Un-spotlight Path_*.

+
image::/v3/07_01_02_AlgorithmPathSpotlight.png[,520,420,role=text-left]
+

. Click *_Un-spotlight Path_* to deselect the path and return the all the data to the graph. The start and end nodes persist in the *_Path Finding_* tab until you remove them, so you can click *_Trace Path_* again.

NOTE: You can use the canvas right-click menu to find a path with a single start and end node. Select the two nodes, then right-click and select *_Find Path_*. To isolate (i.e. spotlight) the resulting path, you must select *_Inverse_*, then *_Hide Selection_*, after which you can tag the nodes in the path and/or save the view.  

== Centrality, Community Detection, and SNA Algorithms

*Kineviz* includes a library of commonly used algorithms which calculate measures of connectedness or clustering (both with respect to distance and strength of connection) in multi-dimensional data. There are many such algorithms, and each has its own characteristic behavior and uses.

image::/v3/07_01_03_AlgorithmsCommunity.png[,720,380,role=text-left]

When you run an algorithm:

* The result for each node in the graph is added as a property and its value. The property values can be used to arrange nodes on the canvas (for example, in a scatter plot or geometric layout), accessed for other processes within *Kineviz*, or exported to other graph analytics or statistics applications.
* For *_Centrality_* and *_Community_* algorithms, you can click *_Color nodes by result_* or *_Color by community_*, respectively, to apply a color scale to nodes according to the algorithm property value.   
* A summary of results for the visible graph is displayed in the algorithm panel. 

*To run an algorithm:*

. In the *_Algorithm_* panel, click to open the *_Centrality_*, *_Community Detection_*, or *_SNA_* tab.
. Click the button for the algorithm you want to run, e.g. *_Louvain_*.

+
image::/v3/07_01_04_Louvain.png[,720,380,role=text-left]
+

+
A message and summary displays when the calculation is finished. The property and calculated value is added to each node in the graph.
. Optionally, click to add a color scale to the node property values.

+
NOTE: You can also review the property values in a table or information window.
