= Load a Saved View

Once a view has been saved, you can load it onto the project canvas at any time. It includes the nodes and edges, the 3D perspective and layout of the graph, and the hidden data as it was when the view was last saved.  

NOTE: A data view is automatically available only in the project where it was created. However, a view exported as .graphxr file or Snapshot archive can be imported to another project, *replacing* its current view. Views saved as a CSV or Excel archive can also be imported to another project, but the data is *added* to the current view.

WARNING: Before you load a saved view be sure to save your current view. You can save it to the current view name, save it as a new view, or export it. 

*To load a saved view to the canvas:*

. You can either:

+
* Use the canvas *View* menu to load a view from the dropdown list. This works best for  recently used views. Simply select the view name from the list of *_recent views_* or *_all views_*.
+
 
+
image::/v3/02_11_01_LoadViewMenu.png[,540,520,role=text-left]
+ 

+
* Open the *_Project > Views_* panel and locate the view in a card or list display. 
+

+
image::/v3/02_11_02_LoadViewPanel.png[,720,520,role=text-left]
+ 

+
TIP: To locate a view quickly, you can search for it by *_Name_* using the view search bar, and/or sort by view *_Name_*, *_Date Created_*, or *_Date Modified_* in ascending or descending order.
+

. Click the card or list item to load the view to the project canvas. 

+
