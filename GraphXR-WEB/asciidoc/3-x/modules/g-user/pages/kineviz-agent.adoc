= Kineviz Agent

*Kineviz* *_Agent_* is a built-in AI assistant for working with graph data in a *Kineviz* project. 

image::/v3/10_01_01_Agent_Overview.png[,520,380,role=text-left]
  
Use the *_Agent_* to turn natural-language questions and instructions into guided graph exploration, data preparation, and analysis. For example, analysts can use the *_Agent_* to move from a question to an actionable graph workflow by suggesting the next operation, explaining graph patterns, and helping prepare data for detailed analysis.

IMPORTANT: Treat generated suggestions as analytical guidance and verify results against your source data.

The *_Agent_*  system prompt includes default canvas context, project context, and interaction mode. A _gxr.agent_ API surfaces sessions, snapshots, and view-copying.
 
In the *_Agent_* panel, you can: 

* Set the agent to work on complex exploratory tasks using natural language prompts.
* Copy Agent code, and Agent responses as .md files to the clipboard. 
* Review skills and tools available to the Agent.
* Manage chat threads.
* Manage views created by the Agent.
* Review current LLM and chat options
* Show or hide the *_Agent_* panel per project using the *_Project > Settings > UI Configuration_*  interface.
* Admin users can open the administrator portal to install specific LLM models, review and manage usage levels and per-user budgets.

NOTE: The *_Agent_* is currently in beta release. Features and behavior may change as the feature evolves.

== Agent Quick Start

The agent is available by default to any individual *Kineviz* user. You can try it out as soon as you open a project. Here's how:

. Log in to *Kineviz* or *Kineviz Desktop*.
. Create or open a project, and on the left panel menu, click *_Agent_*.

+
image::/v3/10_02_01_Agent_OpenAgentPanel.png[,520,380,role=text-left]
+

+
TIP: You can right-click any panel menu item and choose *_Float_* to un-dock the panel from the left menu and reposition it conveniently on the project canvas.
+

. Click the *_New thread_* button.
. Enter the prompt _Create a random graph_ and click *_Send_*.
+
image::/v3/10_02_02_Agent_EnterPrompt.png[,420,380,role=text-left]
+
. Wait for the result. This prompt resulted in a graph of connections among _Persons_ who work for various _Companies_. Your result may vary.
+
image::/v3/10_02_03_Agent_RandomGraph.png[,720,380,role=text-left]
+

+
TIP: For examples of Agent workflows for exploring sample data, try a *Kineviz* Sandbox demo.  

== Create a New Thread

A thread (or chat) is the record of a chat session, including your prompts and the *Agent* responses (code and generated text explanations). Threads persist in the project until you delete them.  

A thread is labeled with the text of the first prompt you enter (e.g. _list my skills_), but it will likely include many other prompts. For example, in a single thread you could enter prompts to create graph data, query a connected database, find paths, lay out the graph in a specific pattern, create and save a grove notebook, and more. 

You can create a new thread at any time.

*To create a thread:*

. Click *_New Chat_* at the top left.
. Enter a prompt (for example, _list my tools_) and click the *_Send_* icon.
+
The thread (or chat) is now labeled with the initial prompt text.

== Rename a Thread

A thread is labeled with the text of its first prompt. You can rename it to be shorter, or more descriptive of the workflow in the thread.

*To rename a thread:*

. Click the *Settings* icon at the top right, and select *_Rename_*
. Enter the new name in the dialog, and click *_Save_*.
+
image::/v3/10_03_01_Agent_ThreadRename.png[,520,180,role=text-left]

 
== Close or Open an Existing Thread

Open threads are shown in separate tabs in the Agent panel. The *_Thread History_* menu lists all the threads you've created (whether currently open or not) in order of when each was last opened. 

*To close a thread:*

. Click the *_X_* icon on the thread tab.
+
The thread is closed (but not deleted). 

*To open a closed thread:*

. Click the *_Thread History_* icon at the upper right. 
. Optionally, use the search bar to search for a thread by name.
. Select the thread from the menu.
+
image::/v3/10_03_02_Agent_ThreadHistory.png[,520,280,role=text-left]
+
The thread is opened in a new tab.

== Delete Threads

You can delete one thread, or clear all threads in a single step.

*To delete one thread:* 

. Open the thread you want to delete.
. Click the *_Settings_* icon at the top right.
. Select *_Delete thread_*

*To clear all threads:* 

. Click the *_Settings_* icon at the top right.
. Select *_Clear threads_*
. Click *OK* (or *Cancel*) in the dialog to confirm (or cancel) the action. 
+
image::/v3/10_03_03_Agent_ThreadClear.png[,240,280,role=text-left]

== Attach Files to a Thread

You can attach files with data or information (text or image) that you want the *Agent* to evaluate in the context of the current prompt. 

*To include an external file in a prompt:*

. Click the *_Attach File_* icon at the bottom left of the panel.
. Navigate to the file and click *_Open_* to add it to the prompt.
. Enter the prompt (e.g. _Find UI elements in the attached image_) and click *_Send_*.
+
The Agent evaluates the attached file according to the prompt and returns its response.
+
image::/v3/10_03_04_Agent_ImageEval.png[,420,280,role=text-left]
 
== Copy Agent Results

Each code block or text response includes an icon to copy results to the clipboard, to transfer to other *Kineviz* projects or for use in reports. 

*To copy Agent code or text responses:*

* Click the copy icon next to a code block or a response.
+
A code block is copied as code, and a response as an .md file.
+
image::/v3/10_03_05_Agent_CopyCodeText.png[,420,280,role=text-left]

*To copy an entire thread to the clipboard:*

. Click the *_Settings_* icon at the top right.
. Choose either *_Copy thread_*, *_Copy thread as Markdown_*, or *_Export as HTML_* from the menu. 

== Review LLMs and Chat options

The LLM menu at the bottom of the *_Agent_* panel shows the currently installed LLMs and highlights the one currently in use (e.g. _Gemini Flash 3 Preview_)

Click the *_Chat Options_* icon next to the LLM menu to see current thinking level and debug options.

*To change LLMs and chat options:*

. Open the LLM menu and choose a different LLM from the menu.
. Click the *_Chat Options_* icon and:
+
* Select a different option from the thinking level menu.
* Click the *_Debug logging_* radio button to turn logging on (or off).
+
image::/v3/10_03_06_Agent_LLMChatOptions.png[,420,280,role=text-left]


== Review Agent Settings

In Agent *_Settings_*, you can review current skills, view usage status and chat options, add or delete LLM models, and review project connector status. 

NOTE: An admin user (either individual, or in a multi-user installation) can access the Admin portal's *_Agent_* panel to include LLMs to be used, and limit daily and overall budgets in terms of both tokens and dollar amounts. 

=== Skills

*To review available agent Skills:*

. Click the *_Settings_* icon at the top right.
. Choose *_Skills_* from the settings menu.

+
The agent *_Settings > Skills_* panel opens, showing the list of skills available to the project.
+

+
image::/v3/10_03_07_Agent_Skills.png[,420,280,role=text-left]
+

. Click the return arrow at the top left to exit agent *_Settings_*. 


=== Usage and LLM Options

The agent *_Settings > General_* panel shows project usage, chat, and LLM options. 

image::/v3/10_03_08_Agent_General.png[,420,480,role=text-left]

*To review usage, chat, and LLM settings:*

. Click the *_Settings_* icon at the top right.
. Choose *_Settings_* from the menu and click to open the *_General_* tab.

+
Options include:

* Review current *_Usage_* as the percent used of the total available across all projects for the logged in user.
* Turn off *_Group work in chat_* to control how agent responses are grouped in a chat. It is turned on by default, which folds each turn's thinking and tool calls into a single collapsible _Worked for…_ row. Turn off the radio button to show every step at the top level.
* Add LLM models. Click *_Add model_* and enter the required Basic and Advanced model details, then click *_Submit_* to add the model (or *_Cancel_* to exit).
+

+
image::/v3/10_03_09_Agent_AddModel.png[,420,380,role=text-left]
+

. Click the return arrow at the top left to exit agent *_Settings_*. 

=== Connector Status 

The agent *_Settings > Connectors_* panel lets you review the connectors (e.g. Firecrawl, Atlassian, etc.) currently available to your project.

image::/v3/10_03_10_Agent_Connector.png[,420,480,role=text-left]

NOTE: Configuration of project connectors is managed through the admin user's *_Admin_* portal.

*To review Connector status:*

. Click the *_Settings_* icon at the top right.
. Choose *_Settings_* from the menu and click to open the *_Connectors_* tab.
. Click the return arrow at the top left to exit agent *_Settings_*.
