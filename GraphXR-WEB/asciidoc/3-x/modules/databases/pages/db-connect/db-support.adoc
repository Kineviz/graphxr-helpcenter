= Kineviz Database Support

The databases that can be connected to *Kineviz* are displayed when you create a project. 

*To review the list of supported databases:*

. Click *_New Project_* at the upper right of the *_Project_* home page. 
. In the *_New Project_* dialog, click *_Your Database_* to display the list.

+ 
image::/v3/01_03_03_CreateDatabaseType.png[,540,320,role=text-left]
+
