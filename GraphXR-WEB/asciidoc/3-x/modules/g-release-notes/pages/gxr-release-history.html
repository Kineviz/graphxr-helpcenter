Kineviz (GraphXR) and Kineviz Desktop Release History

Tag Date Release Highlights

3.30.0

9/30/2026

  • Usability

    • In the project editing menu, Transfer ownership of the project to another user, and optionally remain a collaborator.

    • Additional redesign of the view Save As dialog, including a new Save & share button to save and set sharing details in one click.

    • The Trace Neighbor dialog includes directional trace, and a Select Traced button.

    • Centrality and Community algorithms include a brief description.

  • In Project > Views the folder sidebar is resizeable. Search is enabled for folder names.

  • Agent settings is pinned to the top of the Agent panel, and the agent includes a screenshotCanvas tool, a retry option for model run with no result, and budgets reported as a percentage.

  • Performance

    • Expand on selected nodes longer automatically hydrates node IDs for the entire graph.

    • A size/verbosity rule reduces Agent token cost due to excessively large files.

  • Admin, Security, Configuration, and Deployment

    • Apache AGE (PG 15/16/17/18) is supported.

    • By default, Kineviz Desktop signs in on cloud.kineviz.com.

  • Kineviz API

    • NA

  • Bug Fixes

    • Fly Out no longer frames the graph under the legend.

    • The Map scroll/zoom function works as expected.

    • Renaming a relationship works as expected.

    • Right click + drag to rotate the canvas works in all themes.

    • Deleting a project deletes on files inside its folder, not any others.

  • Extensions

  • The Files panel’s folder explorer sidebar stays visible unless explicitly hidden.

3.29.0

9/22/2026

  • Usability

    • On Edit Project dialog, either Confirm to stay on the Project home page, or Confirm and Open to open the project.

    • Project Toolbar is no longer contextual, is organized in sections, and includes new Gizmo on-canvas layout and Annotate tools.

    • The Information panel enables working with any selection of nodes or edges, not just a single entity at a time.

    • The Legend includes a scrollbar for categories and relationships, rollover tooltip for long category names, and Auto Pick Icons button in the category style setting dialog.

    • Minimap is closed by default.

    • Fly Out centers the graph on the visible canvas.

    • Project editing is available in-project on the split Project/View menu.

    • The Save As view dialog is redesigned, and includes ability share a project.

    • Project > Settings panel includes a Theme Manager menu and in Advanced Settings, a Show recent views on empty canvas checkbox.

    • CSV or Excel import provides options to Import directly or to Create mapping and open the new multi-file Mapping Editor.

    • New SNA tab in the Algorithm panel provides Social Network Analysis (SNA) Algorithms.

    • Project > Settings includes a Theme Manager menu. Advanced Settings includes a Show recent views on empty canvas checkbox (checked by default).

    • Agent system prompt is updated for improved layout and URL fetch, and agent UX improved through Accept / Reject and Retry buttons and options for response to suggested input and transcript viewing.

  • Admin, Security, Configuration, and Deployment

    • UI Configuration allows hiding of Files and Text Editor extensions.

    • Kineviz Marketplace can include Agent skills.

  • Kineviz API

    • gxr.ask() is used to configure AI models for extensions instead of gxr.llm.

    • gxr.agent.run() with tools? and excludeTools? options specifying tool usage.

  • Removed in 3.29.0

    • Agent checkpoint views

    • API: gxr.llm()

  • Extensions

    • The Files panel sidebar is resizeable.

3.28.0

9/15/2026

  • Usability

    • Floating and dockable Canvas picture-in-picture panel

    • Compact Query bar. Click or cmd + K shortcut to open.

    • Mapping Editor redesigned to map multiple CSV or Excel files, either manually or with Auto Map.

    • Agent thread visibiity improved, input dropzone accepts most image and file types, and a Copy thread as markdown is added to its settings menu.

  • Admin, Security, Configuration, and Deployment

    • Kineviz Marketplace introduced.

  • Kineviz API

    • Project > Files API performs checks for project ownership, permissions, and sharing status.

  • Performance

    • Support added to connect additional external databases to a project: Azure, Cosmos, FalkorDB, AlloyDB, Omni, ArcadeDB, Gremlin, JanusGraph, TuGraph, Tiger Graph, Huge Graph.

    • Settings icon in the Extensions panel opens the admin portal to manage extensions.

  • Kineviz API

    • gxr.agent.run() to follow prescribed model selection.

  • Removed
