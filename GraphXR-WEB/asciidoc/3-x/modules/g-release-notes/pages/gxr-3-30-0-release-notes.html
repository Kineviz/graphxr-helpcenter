Kineviz 3.30.0 Release Notes

Release Date: September 30, 2026

Kineviz and Kineviz Desktop include enhanced view saving and sharing, a redesigned Trace Neighbor tool, improved Agent UI and Expand performance, support for Apache AGE, and bug fixes.

In a Kineviz Online or Kineviz Desktop project, to access release notes, click the Kineviz logo at the bottom left, choose About, then click on the release tag.

New Features 3.30.0

Usability Enhancements

  • In Project settings and the in-project split view menu, a Transfer ownership item opens a dialog to transfer ownership of the selected project to another user, and optionally remain a collaborator. (GXR-4703)

  • The view Save As dialog is enhanced with

    • A subtitle stating whether a new view or a saved copy of the loaded view will be created.

    • Suggest button to suggest a view name

    • New Folder inline link to create a new named view folder

    • optional view Description

    • A Saved with it section displaying a canvas thumbnail, node count, and edge count.

    • An Enter saves hint, i.e. pressing Enter or Return saves the view.

    • A new Save & share button that saves and opens the Share dialog for the new view. (GXR-4697).

  • The Trace Neighbor tool is re-designed to include directional trace, and a Select Traced button to select the traced nodes and edges without leaving the dialog. (GXR-677), (GXR-2836).

  • Algorithms in the Algorithm panel’s Centrality and Community tabs include a brief description of their typical use. (GXR-4636).

  • In the Project > Views panel, the folder sidebar is resizeable, and search is enabled for folder names. (GXR-4726).

  • Agent

    • A screenshotCanvas tool is added to enable agent to evaluate an image of the current canvas. (GXR_4727)

    • A new row indicates when a model run returns no result, and provides the option to retry. (GXR_4731)

    • The settings button is now pinned to the top of the Agent panel, and displayed on mouse rollover. (GXR_4733)

    • Budget block messages are reported as a percentage, not in dollars or tokens. (GXR_4757)

Performance Enhancements

  • Expand on selected nodes longer automatically hydrates node IDs for the entire graph, improving speed and reliability, and preventing automatic KoreDB update. Now, moving data on the canvas to KoreDB is done deliberately using Data Store > Hydrate IDs. Unresolved seeds now raise a message saying how many were skipped and pointing at Hydrate IDs (GXR-4670)

    • A size/verbosity rule is added to reduce Agent token cost whereby large files and localization bundles are split according to specific protocols. (GXR_4770)

Administration, Security, Configuration, and Deployment Enhancements

  • Support is added for Apache AGE (PG 15/16/17/18), a PostgreSQL extension that adds graph database capabilities to a regular relational database. (GXR-4761)

  • By default, Kineviz Desktop signs in on cloud.kineviz.com. (GXR-4772)

Kineviz API

NA

Bug Fixes

  • Fly Out no longer frames the graph under the legend. (GXR-4732)

  • The Map scroll/zoom function works as expected. (GXR-4738)

  • Renaming a relationship works as expected. (GXR-4765)

  • Right click + drag to rotate the canvas works in all themes (GXR-4771)

  • Deleting a project deletes on files inside its folder, not any others (GXR-4774)

Removed 3.30.0

  • None
