Kineviz 3.25.0 Release Notes

Release Date: August 28, 2026

Kineviz and Kineviz Desktop include UI changes, performance upgrades and bug fixes. Usability enhancements include project editing from the Projects home page, user-defined project workspaces, and new or re-designed elements in the Legend, context menu, and toolbars. Agent UI is enhanced and and administrator functions reorganized. Database access is added or enhanced for Rocketgraph, AWS Neptune, and Google BigQuery.

In a Kineviz Online or Kineviz Desktop project, to access release notes, click the Kineviz logo at the bottom left, choose About, then click on the current release tag.

New Features 3.25.0

Usability Enhancements

  • From the Projects home page, add a tag, image, description, or sandbox icon to a project tile by opening its Create or Edit dialog. (GXR-4444)

  • When creating a Project, a suggested title is supplied which is used if the user does not enter a title. (GXR-4453)

  • User-defined workspaces.

    • Kineviz panels can be floated on the canvas, docked to the Left, or Right margin, or the the Center of the canvas as desired. Panels docked to the left or right margin can be vertically split. (GXR-4372)

    • A line of icons above the Legend let the user save current panel positions as a named workspace in the project, reset the workspace to the default left panel configuration, open or close docked panels

    • A Peek toggle icon (or shift + Z shortcut) closes (or opens) all panels for a view of the full canvas.

  • Legend re-design

    • The colored dot or line next to a category, relationship, tag, or property now opens the Style Setting dialog, where you choose the color, icon, caption, and/or bind width for the selected element. When you choose an icon, the dot changes to display it. A separate brush icon to open the dialog is no longer present.

    • On mouse rollover, the category name and number of nodes is displayed (in Server, not Desktop). (GXR_4450)

  • Navigation and Selection tools

    • The person icon on the left menu bar at the bottom opens the Account menu with current user name, and the Logout, Settings, About, Shortcuts, Toggle Theme, Recent Projects (for switching to another project), and Home menu items. The Kineviz logo at the top of the left menu bar now returns you to the Projects home page. (GXR-4485)

    • The Account menu stays open until you click elsewhere in the project space. (GXR-4452)

    • GUI Navigation (camera) controls are now redesigned as a line of small icons on the right vertical margin, with added Center To and Fly Out tools. (GXR-4506)

    • The right-click context menu is modernized to be more compact. (GXR-4467)

  • Query

    • The Query panel is refactored to use current UI elements. (GXR-3694)

    • A message is displayed when a query returns no results. (GXR-4471)

    • The Query bar shows case sensitivity in queries more clearly. (GXR-4027)

  • Agent

    • Opening the Agent panel with no open chat tabs (i.e. on first open, or reopening after all tabs were closed) automatically opens a new thread. (GXR-4458()

    • When gxr.agent.run() creates a view, a short view title is proposed based on the visible graph (categories, counts, selection). (GXR-4486)

  • The Login screen is re-designed to conform to Kineviz product design. (GXR-4206)

  • Support is added to vertically split left and right panels (GXR-4372)

Performance Enhancements

  • In the Admin>User panel, one page of a long list of users is loaded at first, reducing wait time (GXR-4483).

  • For Kineviz Desktop, an improved sqlite build is provided. (GXR-4480).

Administration, Security, Configuration, and Deployment Enhancements

  • KoreDB uses the latest kuzu or ladybug version. (GXR-4457)

  • Support is added for Rocketgraph. (GXR-4456)

  • Support is added for the latest AWS Neptune. (GXR-4451)

  • BigQuery includes improved roles description. (GXR-4440)

  • Kineviz Desktop

    • Direct Google login for BigQuery and Spanner. (GXR-4479)

    • A Linux target is added for Kineviz Desktop. (GXR-4443)

  • Kineviz Admin Portal

    • A Secrets manager is provided for both Desktop and Server. (GXR-4487)

    • In the Agent section, the Models sub-tabs is moved to the far left. The five sub-tabs are now Models, Connectors, Budgets, Usage, and Sessions (for server mode only). Models is the tab admins need first because it holds the saved model registry (plus allow user models and MCP Hub toggles). (GXR-4461)

    • Stripe, Legal and Desktop tabs are reorganized. Stripe and Desktop share /api/agent-model-config with the Agent tab; Legal admin routes stay manager-only. (GXR-4462)

Kineviz API

  • gxr.agent.run() to support headless agent operations. (GXR-4441)

  • gxr.screenshot() now includes previously missing category items. (GXR-4003)

Bug Fixes

  • With gxr.query(), reading the wrong QueryResult accessor now raises an instructive error message (rows vs graph) (GXR-4463).

  • The Agent 2.0 static schema card now maintains schema labels properly. (GXR-4439)

Removed 3.25.0

  • None

Extensions 3.25.0
