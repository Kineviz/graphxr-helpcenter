= Getting Started

*Kineviz* (formerly *GraphXR*) is visual analytics platform for exploring the connections in _labeled property graphs_. Graph data defined as *_nodes_* and connected *_edges_* with their associated *_properties_* is rendered as a visual network that you can navigate, edit, analyze, and save within a *Kineviz* project. 

image::/v3/00_01_00_ProjectPropertyGraph.png[,540,340,role=text-center]

A *Kineviz* account lets you create and manage multiple projects, and access many different sources of data.

image::/v3/00_01_01_ProjectHome.png[,720,340,role=text-center]

The Kineviz platform is available as either:      

* *Kineviz Server*, a *multi-user* browser-based application that supports fast, flexible graph modeling and exploration in secure collaborative project workspaces.  

* xref:desktop:desktop-intro.adoc[*Kineviz Desktop*], a *single-user* download that delivers nearly all the functionality of *Kineviz Server* while running locally on your system.
 
== Basic Graph Exploration 

Each *Kineviz* project is a workspace where you can import, model and transform graph data, explore and analyze graph patterns, save your work, and share your insights. 

*Kineviz* projects also include a built-in AI *_Agent_* for optional graph modeling and exploration through AI chat.

== Iterative Visual Analytics with Kineviz 
  
Since exploring a property graph quickly sparks new questions, the workflow is highly iterative. As exploration proceeds, you will most likely want to simplify or transform the graph, edit or add to the data already in the graph, focus on specific subgraphs, and save and communicate key views of the graph as you go.
